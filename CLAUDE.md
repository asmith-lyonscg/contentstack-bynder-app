# Sample files

When a change affects what this app saves or how a website renders it, update the matching sample in the same change.

- `samples/payload/sample-payload-large-hero.json`, `samples/payload/sample-payload-split-left-right.json`, and `samples/payload/sample-payload-custom.json` — one sample payload each (`v`, `profile`, `assets`), not a Contentstack entry. Same Bynder files, different profile snapshots. The custom file uses `profile.id` `"custom"`. Match `persistedPayload` in `src/lib/settings.ts`. `profile.settings.desktop` and `profile.settings.mobile` are aspect-ratio strings. Leave out keys the app does not write: asset `aspectRatio`, `zoom`, a top-level `profileSettings`, and a `focalPoint` of `0.5` / `0.5`. Original size is `origWidth` and `origHeight`. Keep the existing sample assets unless the new shape needs an example they do not cover.
- `samples/react-handler/sample-react-bynder-picture.tsx` — the sample React handler, a `<picture>` for the largeHero payload. It must keep using `buildBynderSources` for the DAT URLs. It passes a width list, and the height comes from the aspect ratio. Neither side may pass `maxDimension` (2000 when the snapshot omits it). largeHero and custom use the standard ladder. splitLeftRight passes a shorter list chosen for `sizes="40vw"`. Update this file when delivery, srcset steps, the max dimension, or the picture markup changes. Leave it alone for editor-only work.
- `samples/html-output/sample-html-large-hero.html`, `samples/html-output/sample-html-split-left-right.html`, and `samples/html-output/sample-html-custom.html` — one sample HTML output each, with the URLs filled in for the matching payload. largeHero uses `sizes="100vw"`. splitLeftRight uses `sizes="40vw"`. custom uses `sizes="100vw"`. `img` `width` and `height` are that picture's desktop request size, not the CSS size. `sizes` is the displayed width. Keep the HTML comment at the top of each file. Write query separators as `&`, not `&amp;`. Regenerate a file whenever its payload or the picture markup changes. Do not add a full document around the picture.

Do not fork the URL math into the sample.
